ZapFast 0.16.5 brings the macOS menu bar back. In 0.16.4 it stopped responding, so Settings, Cmd+, the zoom shortcuts, New Chat, Quit and the Edit shortcuts did nothing on a Mac.

On a Mac, `brew install --cask crmne/tap/zapfast`. On Arch, `yay -S zapfast-bin`.

## Fixed

- **The macOS menu bar works again.** In 0.16.4 the new tray took over the menu's events, so every item in ZapFast's menu bar did nothing: Settings… and Cmd+, (the ways into Settings on a Mac), zoom, New Chat, Close, Quit, Find, and the Edit shortcuts such as Cmd+C and Cmd+V. The menu answers again, and a new test on macOS keeps it that way. By @crmne; thanks @pedrozimmermannsoares for the detailed report. (#215)

## Changed

- **Updates can move to a backed-up signing key.** Release downloads are still signed with the same key, and this version also trusts a second key kept in an offline backup, so a later release can switch keys without anyone having to reinstall. Nothing changes for you now. By @crmne.

@pedrozimmermannsoares for a report precise enough to find the cause quickly, and everyone reporting problems as they find them.
